# NEO ORACLE ARCADE — Web版

「運命の四連スロット」Discord Botのスタンドアロン Web版。ガチャ・プロフィール・履歴・ランキング・
ショップ・インベントリ・キャラ育成/とくぎ変更のソロプレイ経済ループに加え、リアルタイムPvPバトルと
部屋制の協力ボスレイドまで実装しています。

## 構成

```
/server            Express + Socket.IO + Prisma API サーバー
  /src/battle        PvPバトルの対戦エンジン・マネージャー
  /src/raid          協力ボスレイドの対戦エンジン・マネージャー
  /src/socket        Socket.IO 接続/認証/ハンドラ
/web                React + Vite フロントエンド
/packages/game-core  ガチャ抽選ロジック・アイテム・レアリティ・バトル/レイド定数などの共有データ
```

## セットアップ

```bash
npm install

# server/.env は既に開発用の値で作成済み(SQLite・JWTシークレットとも開発用)。
# 本番環境では JWT_SECRET / ADMIN_SIGNUP_CODE を必ず変更し、DATABASE_URL を PostgreSQL に切り替えてください。

npm run build -w packages/game-core
npm run prisma:migrate -- --name init
```

## 開発起動

2つのターミナルで実行してください。

```bash
npm run dev:server   # http://localhost:4000
npm run dev:web      # http://localhost:5173
```

ブラウザで `http://localhost:5173` を開き、新規登録すると最初のユーザーが自動的に管理者(role=admin)になります。

> Vite の依存プリバンドルキャッシュが `packages/game-core` の変更を拾わないことがあります。
> 画面が真っ白になり、コンソールに `does not provide an export named ...` のようなエラーが出た場合は
> `rm -rf web/node_modules/.vite` を実行してから `npm run dev:web` を再起動してください。

## 対戦機能

### ⚔️ バトル(1対1)

`/battle` から表示名でオンラインの相手を検索して挑戦できます。相手が承諾すると専用のバトルルーム
(`/battle/:roomId`)に自動遷移します。

- キャラクター選択 → ターン制バトル(こうげき/ぼうぎょ/とくぎ/一か八か/アイテム/リタイア)
- SPD順に行動が解決され、被ダメージ・回復はHPバー上にフローティング数値でアニメーション表示
- 行動ログは1行ずつ時間差で表示され、戦闘の流れを追いやすくしています
- 切断後20秒操作が無ければ自動的にリタイア扱いになります

### 🐉 レイド(最大4人協力)

`/raid` で部屋の名前とボスを指定してロビーを作成できます。他のプレイヤーは一覧から参加でき、
主催者が開始するとキャラクター選択 → ボス討伐バトルに進みます。

- ボスは6種(業火の悪魔ゲヘナ/氷結の女王リリス/深淵の竜王ヴァルガ/暴風の魔人ヴォルテクス/
  深淵の蜘蛛女王アラクネ/闇の魔導士シェイド)。参加人数に応じてHP/ATKがスケーリングされます
- 5ラウンドごとの弱点(与ダメ1.5倍)、ボス専用技、状態異常(火傷/毒/凍結/封印/攻撃力低下)を再現
- 討伐成功で全員に報酬、最多ダメージのMVPには追加ボーナス、確率でボスドロップ専用アイテムを入手
- 途中離脱・切断時も残りメンバーで討伐を継続できます

## 運営(管理者)権限

`server/.env` の `ADMIN_SIGNUP_CODE`(開発用デフォルト: `ORACLE-STAFF-2026`)を運営スタッフに共有してください。
このコードは以下のどちらかで使用できます。

- 新規登録画面の「運営コード」欄に入力して登録する
- 既存アカウントでログイン後、プロフィール画面の「運営コードで昇格」から入力する

管理者になると、ナビゲーションに「⚙️ 運営」パネルが表示され、以下が行えます。

- ユーザー検索(表示名/メールアドレス)
- 任意のユーザーへのコイン付与(上限なし)
- 任意のユーザーへのアイテム付与(ショップ品・ボスドロップ専用品どちらも指定可、上限なし)
- 登録済み全ユーザーへのアイテム一括配布

本番運用では `ADMIN_SIGNUP_CODE` を必ず推測されにくい値に変更してください。

## データベース

開発用はゼロ設定のSQLite(`server/prisma/dev.db`)を使用しています。本番でPostgreSQLへ切り替える場合:

1. `server/prisma/schema.prisma` の `datasource db` の `provider` を `"postgresql"` に変更
2. `DATABASE_URL` を Postgres接続文字列に変更
3. `npm run prisma:migrate` を再実行

## 動作確認

- 新規登録 → ログイン
- ガチャ(1連/10連/SR以上確定/SSR以上確定)を実行し、コインが減りキャラが増えることを確認
- プロフィール/履歴(レアリティ絞り込み・ページネーション)/ランキングを確認
- ショップでアイテム購入 → インベントリに反映されることを確認
- キャラ育成でレベルアップ、SSR以上のキャラでとくぎ属性変更を確認(同じ属性への変更はボタンが無効化されます)
- 2アカウントでバトルの挑戦→対戦→決着までを確認
- レイドで部屋作成→開始→討伐(または敗北)までを確認
- `npm run prisma:studio` で実データを確認可能

## 既知の制約

- サーバーは単一プロセス前提です(対戦・レイドの状態はメモリ上で管理しており、水平スケールには対応していません)
- 本番デプロイ用のDockerfile等は未整備です
